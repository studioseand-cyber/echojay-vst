## 2. Custom defaults and the reference: the rules as built

Evidence: `tools/ejmap/cert-traces/2026-10-12-custom-defaults/` (census.txt, coverage.txt, factory_validation.txt, PLAN.md).

**The census:** 299 plugins compared at the same version on both Macs.
- 290 open identically;
- 3 differ only in a display or meter control, or within one step;
- 6 differ for real, all MeldaProduction: MTurboCompMB, MMorph, MUnison, MFlangerMB, MTurboComp, MTuner;
- 80 have the same values with Melda's naming setting (not a difference).

**The AU factory preset was rejected as the reference.** On the 289 plugins that open identically, the first factory preset equals
the opening state in 93 of 198 (47%); 91 publish none. That is far below the 95% bar.

**The reference** is the opening block that **2 or more independent Macs agree on** (`kTrustedAgreeing = 2`, confirmed by Kathy).
- **Where:** `<out>/references/<stem>.reference.json` (`ej_instantiate_reference/0`: plugin_id, agreeing, sources, block `[[i, norm, name, text]]`).
- **Before measuring** (Phase B prepare and the certification batch, one implementation, `referenceCheck`): the probe's
  `--factory-preset open` block is compared with the reference (`customdefault::compare`). Not a difference: same displayed text,
  a display or meter control, a name-only difference.
  - **Same** → measured.
  - **Differs from a trusted reference** → every differing control is written back at the reference's norm and read back (the probe
    with `EJ_PROBE_PRESET` on that one call). It is then measured under those writes (Phase B: the child's `--preset`; batch:
    `EJ_PROBE_PRESET` for the product, then cleared). Recorded as `custom_default_restored`.
  - **Differs from a single-source reference, or the read-back does not match** → `custom_default`: not measured, counted with the
    skips (batch: `<cert>/custom_default/<stem>.json`, exit 4). On the wizard it is **held**.
  - **No reference file** → unchanged.
- **The vote** (CD-6): every check casts one: `reference_vote {agrees, agreeing_before, makes_trusted, opening_block when it disagrees}`.
  - A plugin identical to a single-source reference is the second source: measured, and the vote makes the reference trusted.
  - One that differs from a single-source reference stays custom_default until a third source settles it.
- **Strips** (CD-7): the restore writes come first. A section's own write replaces only a control it sets.
  `preset_merge` records which won, per control.
- **Pins:** CD-1..8, WZ-CD-1/2. Every fix's mutants went red.
- **Not re-run live after b24085d5:** Phase B's prepare now calls the shared `referenceCheck`. CD-8 drives that function end to end through
  a fake probe. The earlier live rehearsal ran on 01d3ae20: MMorph and MTurboComp filed custom_default against single-source references;
  with a two-source reference, MTurboComp was restored (all 38 traces carry the writes), but Melda's demo dropouts stopped the
  certification.
